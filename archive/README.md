# Archive

Files of earlier development stages that the final run (`v1.0-full`) does not use. They are kept to document the development described in `docs/DEVELOPMENT_LOG.md`. The working documents are in Hungarian, as they were written during development.

| Folder | Content |
|---|---|
| `notebooks/` | notebooks of the first plan: `001_data_loading_eda`, `002_classical_baseline` (score-cut baseline, macro-F1 0.556), `003_bert_colab` |
| `tests/` | `test_pipeline.py`, smoke test of the first plan, written for an earlier interface of `preprocessing.build_dataset()` |
| `docs/` | environment setup (`KORNYEZET.md`, `KORNYEZET_regi.md`), code guide (`KOD_UTMUTATO.md`), work plans (`MUNKATERV.md`, `PALYAMU_TERV.md`), research log template (`naplo.md`), full run checklist (`FULL_RUN.md`) |
| `results/tables/`, `results/figures/` | outputs of the first plan (01_ and 02_ files from September 2026) and of the subtopic versions before `full2` (v1 without version tag, v2–v5, full) |
| `data/annotation/` | manual check files of the earlier subtopic versions and two optional check files that were not used |
| `data/labels/`, `data/processed/`, `results/models/` | large intermediate files of earlier versions, not stored in Git |
